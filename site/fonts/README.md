# Vendored webfonts

Generated. Do not hand-edit this directory or `../fonts.css` — run
`python3 vendor_fonts.py` from `site/` and commit the result.

**Why these are vendored, what is in here, and how to add a family** is
documented once, in the Typography section of [`../README.md`](../README.md).
This file exists to carry the attribution the OFL asks for.
